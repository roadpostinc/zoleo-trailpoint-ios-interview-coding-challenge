# TrailPoint iOS app

SwiftUI Xcode project for the TrailPoint coding exercise
(`TrailPoint.xcodeproj` in this directory).

- Package overview: [../README.md](../README.md)
- Mock server and API: [../mock-server/README.md](../mock-server/README.md)

## Open in Xcode

```bash
open TrailPoint.xcodeproj
```

## Build and test

To build and run the project:

1. Open `TrailPoint.xcodeproj` in Xcode.
2. Select the `TrailPoint` scheme and your desired simulator/device from the toolbar.
3. Press **Cmd+R** to build and run the app.
4. Press **Cmd+U** to run the unit tests.
